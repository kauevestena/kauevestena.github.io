The **OSM SidewalKreator** QGIS plugin has now passed **23,000 downloads** across all releases from the
[official QGIS Plugin Repository](https://plugins.qgis.org/plugins/osm_sidewalkreator/).

The plugin automates the creation of sidewalk geometries from OpenStreetMap street data, cutting out much of
the manual drawing work involved in building pedestrian network data.

## Key capabilities

- **Automated geometry generation** with customisable offset distances
- **OpenStreetMap tagging compliance** for accessibility attributes
- **QGIS Processing Provider** for batch and scripted workflows
- **Validation tools** for checking output data consistency

## Where to read more

The methodology behind the plugin is described in
[OSM Sidewalkreator: A QGIS plugin for an automated drawing of sidewalk networks for OpenStreetMap](https://doi.org/10.48088/ejg.k.ves.14.4.066.084),
published in the _European Journal of Geography_ (2023). It was also presented at
[State of the Map 2022](https://doi.org/10.5281/zenodo.7004523).

Thanks to everyone in the QGIS and OpenStreetMap communities who has tested the plugin and sent feedback.
