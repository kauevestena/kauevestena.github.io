## About

This repository contains the source code for my personal academic website, built with Jekyll and the al-folio theme. The site showcases my research in:

- **Accessibility Mapping** using OpenStreetMap and open-source tools
- **Geodetic Sciences** and terrestrial mobile mapping technologies
- **Open Source GIS Development** including QGIS plugins and collaborative cartography
- **Urban Planning** with focus on inclusive design and pedestrian mobility

## Featured Projects

### 🗺️ [OSM SidewalKreator](https://github.com/kauevestena/osm_sidewalkreator)

QGIS plugin for automated sidewalk network creation in OpenStreetMap

Collaborative platform for comprehensive pedestrian network mapping

## Technical Details

**Built with:**

- [Jekyll](https://jekyllrb.com/) static site generator
- [al-folio](https://github.com/alshedivat/al-folio) academic theme
- [GitHub Pages](https://pages.github.com/) hosting
- [Jekyll Scholar](https://github.com/inukshuk/jekyll-scholar) for bibliography management

**Key Features:**

- Responsive design optimized for academic content
- Integrated publications management with BibTeX
- Project showcase with detailed case studies
- Professional CV rendered from `_data/cv.yml`
- SEO optimized with comprehensive meta tags
- Accessibility-focused design principles

## Repository Structure

```
├── _bibliography/          # Academic publications in BibTeX format
├── _data/                  # Data files (CV, repositories, etc.)
├── _includes/              # Reusable Jekyll components
├── _layouts/               # Page layout templates
├── _news/                  # News and announcements
├── _pages/                 # Static pages (about, CV, publications)
├── _drafts/                # Unpublished drafts (Liquid syntax references)
├── _posts/                 # Blog posts
├── _projects/              # Research project showcases
├── _sass/                  # Styling and CSS customizations
├── assets/                 # Images, PDFs, and static assets
└── _config.yml            # Site configuration
```

## Local Development

To run this site locally for development:

1. **Install dependencies:**

   ```bash
   bundle install
   ```

2. **Serve the site locally:**

   ```bash
   bundle exec jekyll serve
   ```

3. **View at:** `http://localhost:4000`
